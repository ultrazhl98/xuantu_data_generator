## Project Overview

This is a synthetic training data generation system for mobile gallery/album UI interaction models. It generates realistic Chinese social app screenshots (相册, 微信, 微博, 小红书) paired with natural language instructions and click coordinates for training VLMs/agent models.

**Key output**: JSONL training samples with `{"image": "...", "instruction": "...", "click_targets": [[x,y],...], "selected_grid_indices": [...]}` plus synthetic 1276×2848px screenshots.

## Setup & Commands

```bash
pip install -r requirements.txt
playwright install chromium  # if using Playwright renderer
```

**Prepare test data** (no real photos needed):
```bash
python create_test_photos.py          # generates ~60 placeholder images
python create_test_photos.py --n 10  # 10 per category
```

**Label real photos** (requires Ollama + Gemma 3 model):
```bash
# 前置准备：
# brew install ollama && ollama serve && ollama pull gemma3:4b

python label_photos.py
python label_photos.py --append              # add-only mode for new photos
python label_photos.py --model gemma3:12b    # use larger model
```

**Generate training data**:
```bash
python generate.py --count 100 --apps all
python generate.py --count 10 --seed 42 --debug            # debug mode draws bbox overlays
python generate.py --count 500 --apps 相册,微信 --video-ratio 0.3
python generate.py --count 100 --ensure-labels cat,car     # guarantee these labels appear
python generate.py --n-sequential 3 --n-content 3          # instruction counts per image
```

Key CLI flags: `--count`, `--apps` (comma-sep or "all"), `--seed`, `--debug`, `--video-ratio` (0=no video), `--ensure-labels`, `--n-sequential`, `--n-content`.

## Architecture

```
generate.py (Click CLI)
  └── src/generator.py          # Batch loop: sample → render → annotate → write
        ├── src/source_library.py       # Reads source_photos/metadata.json; sampling with label constraints
        ├── src/app_config.py           # 4 app presets (AppConfig dataclass): geometry, colors, header style
        ├── src/renderer.py             # Pillow-based renderer (status bar, header, grid, nav)
        ├── src/playwright_renderer.py  # HTML/CSS + Playwright renderer (alternative)
        └── src/instruction_generator.py  # Generates 2 instruction types with click coords
```

**Two instruction types** in `instruction_generator.py`:
- **Sequential**: index-based ("send 3rd photo", "send row 2 col 3", "send photos 1,3,5", "send newest N")
- **Content-based**: label-matching ("send all cat photos", "send 2nd dog photo", "send cat and dog photos")

**4 App presets** in `app_config.py` (Album/simple, WeChat/dark, Weibo/search-header, Xiaohongshu/tabs). Each has distinct grid geometry, color themes, and header styles.

**Dual renderers**: `renderer.py` uses pure Pillow (faster); `playwright_renderer.py` uses Pillow + HTML/CSS + Playwright (more visually precise).

**Video support**: Grid cells can be video thumbnails with duration badges. Instruction indexing skips video cells when counting user-visible image indices.

**Metadata format** (`source_photos/metadata.json`): photo catalog with labels and timestamps, generated by `label_photos.py` via local Gemma 3 model (Ollama).

## Important Conventions

- Output files go to `output/` (gitignored): `output/images/`, `output/debug/`, `output/training_samples.jsonl`
- Source photos go to `source_photos/images/` (gitignored); metadata at `source_photos/metadata.json`
- Image dimensions are fixed at 1276×2848px (mobile screenshot)
- Chinese app names are used directly as identifiers (相册, 微信, 微博, 小红书)
- When adding new instruction types, follow the pattern in `instruction_generator.py`: return list of `{"instruction": str, "click_targets": [[x,y]], "selected_grid_indices": [int]}` dicts
